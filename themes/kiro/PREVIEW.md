# Kiro Face Theme - 预览

## 主题概览

Kiro Face 是一个基于可爱蓝色圆脸设计的 Clawd on Desk 主题，具有以下特点：

- 渐变彩虹边框（青色→蓝色→绿色）
- 眼睛实时追踪鼠标
- 丰富的表情和动画
- 纯 SVG 矢量图形，任意缩放不失真

## 状态展示

### 核心状态

#### 空闲 (Idle)
- 眼睛跟随鼠标移动
- 自动眨眼（每 4 秒）
- 身体轻微倾斜
- 阴影随鼠标方向拉伸

#### 思考 (Thinking)
- 眼睛左右移动
- 光环脉冲发光
- 外圈呼吸效果

#### 工作 (Typing)
- 快速眨眼（0.8 秒周期）
- 轻微上下弹跳
- 表示正在执行工具

#### 构建 (Building)
- 戴上魔术师高帽
- 帽子左右摇摆
- 开心的弯弧眼睛
- 表示多会话工作

#### 杂耍 (Juggling)
- 眼睛上下移动
- 表示处理子代理

#### 开心 (Happy)
- 弯弧笑眼 ^_^
- 弹跳庆祝动画
- 任务完成时显示

#### 通知 (Notification)
- 惊讶的大圆眼
- 眼睛高光闪烁
- 脉冲放大效果
- 权限请求时显示

#### 错误 (Error)
- 难过的倒弧眼
- 流泪动画
- 左右摇晃
- 红色渐变边框

### 睡眠序列

#### 打哈欠 (Yawning)
- 半闭的眼睛
- 身体纵向拉伸
- 张开的嘴巴

#### 睡眠 (Sleeping)
- 闭眼横线 -_-
- Z Z Z 向上飘起
- 呼吸动画（缓慢缩放）

#### 醒来 (Waking)
- 眼睛从闭到睁
- 身体摇晃旋转
- 从睡眠恢复

### 工作状态

#### 清扫 (Sweeping)
- 左右摇摆
- 表示清理上下文

#### 搬运 (Carrying)
- 上下移动
- 表示创建工作树

### 随机空闲动画

#### 四处看 (Look Around)
- 眼睛左右移动
- 3 秒动画
- 空闲时随机触发

## 交互反应

### 拖拽 (Drag)
- 惊讶的大眼睛
- 持续左右摇摆
- 拖动时循环播放

### 左击反应 (Click Left)
- 左眼眨眼
- 向左倾斜 15°
- 2.5 秒后恢复

### 右击反应 (Click Right)
- 右眼眨眼
- 向右倾斜 15°
- 2.5 秒后恢复

### 双击反应 (Double Click)
- 360° 旋转
- 爱心飘起
- 腮红显现
- 3.5 秒动画

## 颜色方案

### 主色调
- **边框渐变**: `#4fc3f7` → `#2979ff` → `#69f0ae`
- **眼睛**: `#2979ff` (蓝色)
- **背景**: `#e8f4ff` (浅蓝)
- **阴影**: `rgba(0,0,0,0.1)`

### 特殊状态颜色
- **错误边框**: `#ff6b9d` → `#ff1744` → `#ff6b9d` (粉红渐变)
- **错误背景**: `#ffe8f0` (浅粉)
- **爱心**: `#ff6b9d` → `#ff1744` (粉红渐变)
- **魔术帽**: `#1565c0` → `#2979ff` (深蓝渐变)

## 动画技术

所有动画使用 CSS `@keyframes`，包括：

- **transform**: 位移、旋转、缩放
- **opacity**: 淡入淡出
- **SVG 属性动画**: ry (眼睛高度), r (圆半径)
- **filter**: 发光效果 (feGaussianBlur)

## 使用建议

### 最佳尺寸
- **小**: 64px (托盘图标风格)
- **中**: 120px (默认推荐)
- **大**: 200px (演示展示)

### 适用场景
- 适合长时间编程陪伴
- 可爱风格，减轻工作压力
- 清晰的状态反馈
- 不会过于干扰注意力

### 性能
- 纯 CSS 动画，GPU 加速
- 无 JavaScript 运行时开销
- 每个 SVG 文件 1-2KB
- 流畅运行在所有平台

## 自定义建议

如果你想修改主题：

1. **改变颜色**: 编辑 SVG 中的 `linearGradient` 定义
2. **调整动画速度**: 修改 `@keyframes` 的 duration
3. **添加新表情**: 复制现有 SVG，修改眼睛形状
4. **调整眼睛追踪**: 修改 `theme.json` 中的 `maxOffset`

## 技术规格

```json
{
  "viewBox": "-2 -2 28 28",
  "eyeTracking": {
    "maxOffset": 2,
    "bodyScale": 0.2,
    "shadowStretch": 0.1
  },
  "objectScale": {
    "widthRatio": 2.0,
    "heightRatio": 2.0
  }
}
```
